Quest stages

Story progress is not a set of flags: each quest is one Enum save field whose value is the MurmurHash3 of the current stage name. The game checks progress with expressions such as Get_StoneOfForest_IsCompleted_Exp (stage == Complete) and ..._IsAfter_DefeatBoss_Exp (stage ≥ DefeatBoss), so setting a quest's stage is what makes the world react. Changes show after a loading zone.

In ootmenu: story page, one selector per quest.
