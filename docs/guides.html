Tutorial guides (ActionGuide_IsEnd)

The game records which tutorial screens ("action guides") the player has seen in the struct ActionGuide_IsEnd: one Bool field per guide type. Some features stay hidden until their guide has been seen. Example: the D-pad (Navi, item shortcuts, ocarina) only appears once the Navi guide, normally shown on entering the Deku Tree, is marked seen.

In ootmenu: story → all tutorials seen.
