Save fields

Every field in the game's GameDataList (romfs GameData/GameDataList.Product.110.byml.zs). Each field is keyed by the MurmurHash3 (seed 0) of its name. Name is the game's own name, recovered by hashing strings found in the game's scripts; editor title comes from the onif save editor where known. Fields with 64-bit keys (Bool64bitKey) aren't listed.
